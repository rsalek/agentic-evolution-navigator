# Okta makes Agent SSO generally available

Okta made Agent SSO generally available on August 24, 2026. The product registers Cross App Access-compatible agents in Universal Directory, replaces stored credentials with short-lived identity-governed tokens, and applies enterprise access policy through the same administrative workflows used for employees.

Agent SSO is included in core Okta SSO plans at no additional cost. The broader Okta for AI Agents product, which adds discovery, ownership, lifecycle governance, approval workflows, runtime enforcement, and a kill switch across agents, is available as a separate subscription. Okta says the core identity product is used by more than 20,000 customers, but this is an installed-base figure rather than Agent SSO adoption.

## Commercial-evidence gate

This is **identity-control and distribution readiness, not a monetization green shoot**.

- **Payer and toll gate:** Existing Okta SSO customers receive Agent SSO without incremental price; a customer can upgrade to the separately subscribed Okta for AI Agents control plane.
- **Revenue bridge:** The free core feature may create an attach funnel into a paid agent-governance subscription, but Okta discloses no Agent SSO adoption, paid attach, price, customer wins, renewal, ARR, or agent-attributed revenue.
- **Measured period and denominator:** General availability began August 24. The 20,000-customer figure covers Okta's broader installed base and cannot be treated as an agent-product denominator.
- **Repeatability and attribution:** The identity-provider position is structurally repeatable across agent connections, but no active-agent, token, authorization, incident, audit, policy, or subscription metric is reported.
- **Strongest falsifier:** Low protocol coverage, low upgrade attach, or commoditization of agent identity inside core SSO would prevent the separate governance layer from becoming a material tollbooth.
- **Next verification trigger:** Named Agent SSO production customers, active agents and connections, Cross App Access coverage, Okta for AI Agents pricing and attach, renewal, agent-attributed ARR, and measured security or audit outcomes.

## Cross-event dynamics

The release strengthens incumbent distribution: agent identity is inserted into an existing enterprise control plane and integration network. It simultaneously challenges independent trust-infrastructure monetization because the basic control is bundled free, leaving economic capture dependent on paid governance attach.
