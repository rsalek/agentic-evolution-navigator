# MongoDB launches priced Atlas Agent Engine preview

MongoDB launched Atlas Agent Engine in public preview. Atlas Agent Runtime and Atlas Agent Memory use consumption-based pricing and can draw on a customer's existing Atlas commitment without a new contract. MongoDB names Paysafe as building toward production and cites more than 70,000 Atlas customers as the distribution base, not as Agent Engine users.

## Commercial evidence gate

This is an emerging pricing and attach green shoot, not evidence of realized Agent Engine revenue or production adoption.

- Payer: an existing or new MongoDB Atlas customer consuming Agent Runtime or Agent Memory.
- Customer or market-share evidence: Paysafe is a named pre-production customer; the 70,000-customer Atlas base is addressable distribution, not attach or adoption.
- Toll-gate mechanism: metered Runtime and Memory consumption charged against paid Atlas commitments.
- Revenue or economic bridge: agent workloads can consume an existing contracted budget and potentially expand Atlas consumption without a new procurement step.
- Measured period and baseline: public preview launched September 29, 2026; no paid-preview period, consumption baseline, attach rate, or revenue is reported.
- Repeatability and attribution: the usage meter is repeatable and agent-product-specific, but no recurring customer consumption or incremental contract value is measured.
- Still unproven: paid users, active agents, consumption volume, incremental revenue, renewal, workload quality, unit cost, and margin.
- Strongest falsifier: preview usage stays free or low and merely reallocates existing Atlas spend without expanding consumption or retention.
- Next verification trigger: general availability, paid attach, active agents, commitment consumption, incremental revenue, renewal, and margin disclosure.
