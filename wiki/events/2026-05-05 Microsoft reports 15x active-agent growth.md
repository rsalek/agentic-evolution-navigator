# Microsoft reports 15x active-agent growth

Microsoft's 2026 Work Trend Index reported that unique active agents across the Microsoft 365 Copilot Agents platform and SharePoint agents grew 15x year over year from March 2025 to March 2026.

## Why it matters

This is direct provider telemetry showing rapid growth in agent objects that reached at least minimal live use inside an incumbent enterprise platform. It strengthens the evidence that existing workplace systems distribute agent use.

## Evidence boundaries

Microsoft publishes a ratio but no absolute agent, run, user, or firm count. An agent counts as active if it has at least one day of user-initiated usage in a rolling 28-day period or completes at least one autonomous run. The metric therefore establishes production activity and directional growth, not scaled task volume, sustained use, outcomes, or economics.
